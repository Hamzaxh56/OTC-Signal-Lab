QUOTEX SIGNAL LAB LITE V2
This is a simple static website for GitHub Pages. It includes a broader set of common forex, metal, crypto and index symbols, a TradingView chart, and a basic EMA/RSI signal analysis request through Twelve Data.

Important limitations:
- It is NOT connected to Quotex's internal market feed and cannot guarantee all Quotex markets.
- Quotex OTC prices may differ from external feeds.
- No 90% or other win rate is claimed. A win rate needs a documented historical backtest and realistic expiry rules.
- Twelve Data may not support every symbol/interval on every plan.
- Browser API keys are visible to visitors on a public website. For production/public use, put API calls behind a server-side backend.

Publish on GitHub Pages:
1. Extract ZIP on phone.
2. Create repository on github.com.
3. Upload index.html directly to repository root (not nested in a folder).
4. Repository Settings -> Pages -> Deploy from a branch.
5. Select main and /(root), Save.
6. Wait for GitHub Pages URL.
