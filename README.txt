QUOTEX SIGNAL LAB V3 — QUICK SETUP (ANDROID)

1. Download and extract this ZIP.
2. Upload index.html directly into the ROOT of your GitHub repository (not inside another folder).
3. In GitHub open Settings → Pages.
4. Under Build and deployment choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish, then open the website link.

HOW TO USE
- Choose a pair and timeframe.
- Paste your Twelve Data API key and tap Analyze market.
- BUY or SELL only appears when this simple EMA/RSI/candle rule agrees. WAIT means no clear setup.
- A BUY/SELL signal gets a countdown equal to the selected timeframe: 1m=60s, 5m=300s, 15m=900s, 30m=1800s, 1h=3600s, 4h=14400s. When it reaches zero, the signal changes to EXPIRED.
- The countdown starts when analysis completes; it is not a broker-confirmed expiry time.

IMPORTANT
- No strategy can guarantee profit or prevent all losses. No winning percentage is claimed; the website does not calculate a verified historical win rate.
- This is not connected to Quotex's private price feed and does not place trades.
- OTC symbols may not match public market data and may be unavailable.
- Twelve Data symbol support and request limits depend on your account plan.
- A key entered into a public static website can be visible to visitors. For a public production website, use a backend to protect the API key.
- Use a demo account first. Avoid borrowing or risking essential money.
